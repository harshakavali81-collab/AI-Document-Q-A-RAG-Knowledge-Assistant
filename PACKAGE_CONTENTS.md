# Package contents

This ZIP contains the runnable project, two PDFs, evaluation Excel/CSV/JSON, diagram PNG/SVG/Mermaid files, sample documents, tests, setup and interview guides.

No API keys, installed dependencies, downloaded model weights, private uploads or generated private indexes are bundled. Live semantic/LLM operation and public hosting still require setup.
